# 文档目录

本目录主要整理 Windows Qt 人脸考勤控制台资料。第 09 号文档仅记录跨项目协作的交接结论，不包含 RK3568 网关源码、构建产物或可执行部署内容。

建议按编号阅读：

| 编号 | 文件 | 内容与适用场景 |
|---|---|---|
| 01 | `01-项目实施记录与下一步.md` | 已完成操作、验证结论、未完成项和下一步实施顺序；日常开发以此为准。 |
| 02 | `02-项目问题汇总-通俗版.md` | 用于自己复盘、和非技术协作者沟通。 |
| 03 | `03-项目问题汇总-面试版.md` | 用于面试介绍、追问准备和成果边界核对。 |
| 04 | `04-项目升级实施方案.docx` | 完整项目升级方案，适合系统性阅读或对外提交。 |
| 05 | `05-RK3568协作边界.md` | 与上游网关的强制协作边界；跨项目动作前必须遵守。 |
| 06 | `06-人脸考勤项目面试答辩手册.docx` | 面试与答辩速查手册，含 60 秒介绍、架构图、函数调用链和 40 个高频问答。 |
| 07 | `07-本轮开发与演示总结.md` | 本轮功能开发、演示问题、验证证据和下一次继续开发的交接清单。 |
| 08 | `08-Windows便携包验收清单.md` | 本机隔离验证、干净 Windows 机器人工验收步骤和结果边界。 |
| 09 | `09-RTSP与RK3568网关MPP排障交接.md` | 本轮 Qt/网关协作的事实记录、MPP 排障状态、未完成项和下一段对话提示词。 |

`附录-文档制作资料` 保留生成 Word 方案所用的脚本、模板提炼说明和迁移前的英文说明，供维护文档时查阅，不是项目运行必需文件。

## 状态标记

- **已完成**：已经修改并至少完成构建或启动验证。
- **部分完成**：已建立基础机制，但完整业务闭环未完成。
- **待实现**：只写入计划，不能作为当前成果陈述。
- **等待网关**：依赖上游 RK3568 网关完成并验收 RTSP 接口后才能联调。
