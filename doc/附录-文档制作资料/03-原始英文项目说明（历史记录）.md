# FaceRecognition (Qt 5 baseline)

This workspace is a cleaned and buildable baseline migrated from the original
Qt/OpenCV/SeetaFace attendance demo. It intentionally uses the installed Qt
5.12 MinGW 7.3 kit first; a Qt 6/CMake migration is a later phase.

## Current baseline

- Qt 5.12.0, MinGW 7.3 64-bit
- OpenCV 4.5.2 and SeetaFace2 from the supplied course package
- SQLite attendance database in a configurable application-data directory
- Model directory, recognition threshold, and attendance cooldown configured
  through environment variables

The first repair batch removes the hard-coded `C:/SeetaFace` model path, fixes
the attendance timestamp schema, uses parameterized SQL for registration and
attendance writes, rejects matches below a threshold, and passes cloned camera
frames into the recognition worker.

## Build on this machine

The local `D:/qtdeps` directory is a junction to the provided OpenCV/SeetaFace
package. It exists only to give MinGW an ASCII-only dependency path.

```powershell
$env:PATH = 'D:\QT\Tools\mingw730_64\bin;D:\QT\5.12.0\mingw73_64\bin;' + $env:PATH
New-Item -ItemType Directory -Force build-qt5-mingw-release | Out-Null
Set-Location build-qt5-mingw-release
& 'D:\QT\5.12.0\mingw73_64\bin\qmake.exe' '..\src\FaceRecognition.pro' -spec win32-g++
& 'D:\QT\Tools\mingw730_64\bin\mingw32-make.exe' -j 4
```

## Run in the development environment

```powershell
$env:PATH = 'D:\QT\5.12.0\mingw73_64\bin;D:\QT\Tools\mingw730_64\bin;D:\qtdeps\opencv452\x64\mingw\bin;D:\qtdeps\SeetaFace\bin;' + $env:PATH
$env:FACE_ATTENDANCE_MODEL_DIR = 'D:\qtdeps\SeetaFace\bin\model'
$env:FACE_ATTENDANCE_DATA_DIR = "$PWD\runtime-data"
& '.\build-qt5-mingw-release\release\FaceAttendance.exe'
```

Optional settings:

- `FACE_ATTENDANCE_SIMILARITY_THRESHOLD`: default `0.70`; tune it only after
  collecting test data.
- `FACE_ATTENDANCE_COOLDOWN_SECONDS`: default `30`; prevents duplicate
  attendance records for the same employee.

## Do not commit

`third_party.pri`, build directories, generated runtime data, and the external
dependency junction are machine-specific and are ignored by Git.

The `scripts` directory contains repeatable build, development-run, and Windows
packaging commands.
